Implementation highlights
Six choices that make it work

Finance-trained AI models

FinBERT for English; XLM-RoBERTa plus a multilingual NLI model for other languages.

Why: reads context, not keywords

Impact learned from prices

A gradient-boosting model trained on 74,964 news items and the price moves that followed.

Why: grounded in real reactions

Cheap filters first

64% of documents mention no tracked company and stop before the AI; duplicates merge.

Why: fast on a laptop CPU

Never goes dark

Every source has a recorded replay that takes over when it fails.

Why: the demo runs fully offline

Module A · Index rebalancer

20 S&P 100 stocks tilt towards good news, inside hard limits (15% per stock, 35% per sector).

Why: news-aware, risk-controlled

Module B · Stress test

A confirmed serious event re-prices 300 positions and runs 10,000 scenarios in 0.2 s.

Why: a capital number in seconds

Assumptions & next steps
Built to grow into a production system

Assumptions

  • Synthetic, seeded bank book; public data only
  • Stress shocks scale with the Impact Score from real past episodes
  • Recorded finance tweets stand in for X, which has no free API

Next steps

  • Human-labelled native-language data to raise multilingual accuracy
  • Connect real exposure feeds in place of the synthetic book
  • GPU or INT8 workers for higher volume
  • Intraday price labels for a sharper Impact Score
